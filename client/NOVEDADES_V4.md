# Mi Campo V4 — intuición y vacíos familiares

Esta versión amplía la modalidad Familiar para trabajar con historias incompletas, adopción, familia biológica desconocida y generaciones de las que no se tiene información.

## Nuevas opciones

- **Orígenes desconocidos · intuitivo** como estructura familiar.
- Nuevos comienzos rápidos:
  - Familia biológica desconocida · mapa intuitivo.
  - Ancestros desconocidos · exploración intuitiva.
  - Vacíos de mi historia familiar.
- Generador de figuras intuitivas a partir de lo que el usuario siente:
  - una presencia;
  - una ausencia;
  - una figura ancestral;
  - rama materna o paterna desconocida;
  - presencia femenina o masculina imaginada;
  - figura protectora;
  - recurso ancestral imaginado;
  - algo todavía sin nombre.
- Campo puede generar automáticamente tres figuras simbólicas editables.
- El usuario puede escribir su propia figura intuitiva con cualquier palabra o imagen que le venga.
- Las figuras intuitivas quedan identificadas internamente como `hypothetical: true` y `source: intuition`.
- Durante la colocación, la guía invita a usar distancia, orientación y postura de manera intuitiva.
- Preguntas de observación específicas para sesiones de orígenes desconocidos.
- Nueva lectura **Relato intuitivo de lo desconocido**, que construye una narración simbólica usando:
  - posición;
  - cercanía o distancia;
  - postura;
  - figura que ocupa el centro;
  - sensaciones o palabras registradas por el usuario.
- El relato puede regenerarse con **Otra lectura** y descartarse con **No me resuena**.

## Cómo se manejan los vacíos

La app sí puede inventar personajes, ramas y narrativas para completar simbólicamente un mapa desconocido. Estas creaciones funcionan como elementos de ficción introspectiva de esa sesión: sirven para explorar lo que evoca el vacío sin tratarlas como nombres, parentescos o acontecimientos recuperados de la historia real.

## Compatibilidad

Mantiene todo lo de V3: modo normal/oscuro, navegación animada, adicciones, exploraciones hipotéticas, campo digital, posturas, interpretaciones, Axoflutter 3D, historial, voz, PWA y almacenamiento local.
