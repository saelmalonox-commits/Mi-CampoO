# Importación en Google AI Studio

1. Build → Web app.
2. Add files (+) → Import from GitHub, o sube este ZIP como fuente del proyecto.
3. En Secrets confirma `GEMINI_API_KEY`; no la copies al cliente.
4. Pega `docs/AI_STUDIO_MEGAPROMPT.md` como primera instrucción de migración.
5. Pide primero **RUN + AUDIT, NO REWRITE**.
6. Cuando la app corra, sincroniza con GitHub desde Settings → GitHub.
7. Despliega sólo después del checklist P0.
