OBJETIVOS:
1. Mantener todo el motor local y todas las rutas funcionales.
2. Hacer que el Inicio se acerque visualmente a `docs/references/HOME_VISUAL_TARGET.jpeg` utilizando componentes interactivos reales, no un screenshot plano.
3. Mantener Axoflutter grande y visible; GLB cuando funcione y fallback de imagen si falla WebGL.
4. Mantener tres universos claramente diferentes × claro/oscuro con movimiento y sonido propios.
5. Mantener generador abierto de constelaciones completas, prácticas personalizadas e intuición hipotética.
6. Integrar Gemini desde servidor: texto/facilitador, generación de constelaciones, TTS y Live con token efímero.
7. No exponer `GEMINI_API_KEY` al cliente.
8. Mantener PWA iPhone, safe areas, touch targets, accesibilidad y offline del motor local.
9. Durante una constelación, una sola instrucción principal por pantalla y ritmo OBSERVACIÓN → RESPUESTA → SIGUIENTE PASO.
10. Antes de finalizar cualquier cambio, ejecutar `npm run check` y revisar `docs/ACCEPTANCE_TESTS_09_4.md`.

No reemplaces lenguaje intuitivo por advertencias repetitivas. Las lecturas sistémicas pueden ser profundas y creativas, formuladas como hipótesis explorables que el practicante puede aceptar o descartar.
