# Contrato visual · Inicio CAMPO

Referencia visual obligatoria: `docs/references/HOME_VISUAL_TARGET.jpeg`.

La imagen no se usa como screenshot de fondo. Es una referencia de composición. El Inicio real debe seguir siendo interactivo, accesible y adaptable a iPhone.

## Composición objetivo
- Encabezado flotante: perfil a la izquierda y campana a la derecha.
- Título editorial dorado `CAMPO` y subtítulo `EXPLORACIÓN SIMBÓLICA GUIADA`.
- Axoflutter ocupa la zona hero y es el protagonista visual.
- Menú radial: Historial arriba-izquierda, Continuar arriba-derecha, Iniciar constelación al centro, Ajustes abajo-izquierda, Biblioteca abajo-derecha y Modalidades abajo-centro.
- Tarjeta `GUÍA VIVA` con retrato de Axoflutter, saludo y acción `Conectar con mi guía`.
- Navegación inferior: Inicio, Explorar, Prácticas, Diario, Respirar.
- Materiales: vidrio 3D, oro, reflejos húmedos, profundidad, partículas, orbes, estrellas y movimiento suave.

## Reglas
- Cada control de la referencia debe ser un control real. No convertir la pantalla completa en una imagen.
- La composición debe seguir siendo legible con safe areas, Dynamic Island y barra inferior del iPhone.
- En PWA standalone, aprovechar toda la altura disponible mediante `100dvh` y `env(safe-area-inset-*)`.
- Durante una constelación activa, reducir la intensidad del escenario para priorizar una sola instrucción y una sola acción principal.
- Axoflutter conserva identidad entre mundos; sólo cambian iluminación, partículas y movimiento.
