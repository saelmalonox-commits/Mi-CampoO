# Mi Campo V6.1 · Pulido iPhone

Esta actualización conserva la lógica y los datos de V6 y se concentra en la experiencia visual del Home en iPhone.

- Home radial con jerarquía más clara y sin accesos duplicados con la barra inferior.
- Axoflutter más grande, visible y con acceso directo a voz/sonido/acompañamiento.
- El acceso ambiguo superior se reemplaza por Ajustes.
- El acceso “Sesiones” desaparece cuando no existe una sesión abierta; “Continuar” aparece solo cuando corresponde.
- Nodos radiales para Modalidades, Laboratorio, Mapa familiar y Constructor.
- Textos secundarios de nodos en dos líneas, sin truncado con “…”.
- Barra inferior más compacta y mejor uso de safe-area.
- Ajustes de altura y proporciones para iPhone / PWA standalone.
- Nueva versión de caché del service worker para evitar que la V6 anterior quede retenida.

No se modificó la lógica simbólica, los modos de constelación, el almacenamiento, cifrado, historial, importación/exportación ni el modelo de datos.
