# Mi Campo V3 — cambios integrados

## Apariencia
- Modo **Oscuro · cosmos profundo**.
- Modo **Normal · aurora clara**.
- Cambio rápido desde la barra superior y selector completo en Ajustes.
- Colores, tarjetas, campo digital, modales y navegación adaptados a ambos modos.

## Movimiento y navegación
- Transición animada al entrar a cada vista.
- Anillos orbitales con movimiento en Inicio.
- Nodos del menú circular con flotación suave.
- Pulso luminoso del centro "Iniciar constelación".
- Respuesta animada del elemento activo en la navegación inferior.
- Ajuste de movimiento: Suave / Expresivo / Reducido.
- Respeta `prefers-reduced-motion`.

## Lectura simbólica contextual
En temas marcados como hipotéticos, Campo puede construir narrativas ricas a partir de:
- posición;
- orientación;
- postura de pie / acostada / inclinada;
- cercanía y distancia;
- aislamiento;
- cambios entre configuración inicial y actual.

La lectura mantiene el tema como hipótesis simbólica o manera de nombrar la experiencia, en vez de tratar la disposición como una prueba de una causa externa.

En adicciones/consumo/compulsiones, las lecturas priorizan impulso, necesidad, consecuencias, límites, apoyos y recursos sin imponer una causa única.
